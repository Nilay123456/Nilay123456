## How I Think About Projects

I try to make projects explainable, not just functional:

- What problem does this solve?
- What tradeoffs did the architecture make?
- What breaks at scale?
- What would I change for production?
- How can the output be verified?

## Current Focus

- System design fundamentals: caching, databases, queues, scaling, reliability
- DSA pattern practice with reusable mental models
- Making projects easier to verify through READMEs, tests, demos, and architecture notes
